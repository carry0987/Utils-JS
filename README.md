# Utils-JS

Documentation site for `Utils-JS`, a focused utility library for universal and browser-only JavaScript helpers.

## Stack

- Docusaurus 3
- React 19
- TypeScript
- pnpm

## Requirements

- Node.js 24 or newer
- pnpm

## Development

Install dependencies:

```bash
pnpm install
```

Start the local docs site:

```bash
pnpm start
```

Build the production site:

```bash
pnpm build
```

Serve the built site locally:

```bash
pnpm serve
```

## Useful Commands

```bash
pnpm typecheck
pnpm lint
pnpm clear
```
